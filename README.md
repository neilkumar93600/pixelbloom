# AI SEO Growth Engine

A production-focused blueprint for building an AI-powered SEO SaaS platform (inspired by Ahrefs, SurferSEO, and Screaming Frog) using Next.js, Supabase, and OpenAI.

## What's Included

- Full system architecture and scalability plan
- PostgreSQL/Supabase schema
- API route design (Next.js App Router + Edge Functions)
- Next.js folder structure
- UI component and page plan
- AI prompt templates for core SEO automations
- Example SEO audit output
- Example programmatic SEO page outputs
